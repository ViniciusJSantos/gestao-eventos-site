Sobre o Projeto

O Sistema de Gestão de Eventos é o projeto integrador desenvolvido pelos alunos da disciplina de Tecnologias Web. Ele reúne, em um unico site, a divulgação e a inscrição em eventos do Campus Paulo Afonso
   "Um site simples, feito só com HTML, CSS e JavaScript, pode resolver um problema real da comunidade acadêmica."
Para saber mais acesse o repositorio do projeto ou entre em contato pelo e-mail eventos@ifba.edu.br.
